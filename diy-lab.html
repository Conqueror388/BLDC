Spin a BLDC Motor with Arduino & ESC

An Electronic Speed Controller (ESC) encapsulates the 3-phase MOSFET bridge and sensorless commutation processor. By transmitting standard servo pulses (1000μs to 2000μs at 50Hz), a microcontroller commands throttle velocity with precision.

[ELECTROMECHANICAL INTERCONNECTION SCHEMATIC] PINOUT GUIDE

Electrical Hookup Rules

  1. PWM SIGNAL (WHITE/ORANGE): Tie to Arduino digital Pin 9 (timer hardware PWM output).
  2. COMMON REFERENCE GND: Tie ESC signal GND (black wire) directly to Arduino GND plane. Floating ground causes severe jitter.
  3. RED 5V BEC LEAD: DISCONNECT / TAPE OFF if Arduino is powered over USB to prevent dual-regulator bus contention.
  4. MOTOR PHASE REVERSAL: Swapping any two of the three motor phase leads immediately inverts rotation direction (CW ↔ CCW).
  5. ANALOG POTENTIOMETER: Connect wiper to Analog Pin A0; outer legs to 5V and GND rails.

BLDC_Throttle_Control.ino (50Hz RC PWM) 1000μs – 2000μs BOUNDS 
#include <Servo.h>

Servo esc;

const int ESC_PIN = 9;   // Hardware PWM pin attached to ESC signal
const int POT_PIN = A0;  // 10k potentiometer center wiper on Analog 0

void setup() {
  Serial.begin(115200);
  
  // Attach ESC on Pin 9 with 1000us - 2000us standard bounds
  esc.attach(ESC_PIN, 1000, 2000);
  
  // MANDATORY ARMING SEQUENCE:
  // Write 1000us (idle throttle) to clear ESC boot lockout
  esc.writeMicroseconds(1000);
  Serial.println("[ARMING] Transmitting 1000us idle pulse...");
  delay(3500); // Wait for confirmation readiness beeps
  Serial.println("[SYSTEM READY] ESC armed. Slowly advance throttle potentiometer.");
}

void loop() {
  int rawValue = analogRead(POT_PIN); // 0 to 1023
  int pulseWidth = map(rawValue, 0, 1023, 1000, 2000);
  
  esc.writeMicroseconds(pulseWidth);
  delay(20); // 50 Hz frame refresh rate
}
ESP32_LEDC_PWM.ino (Hardware Timer PWM) 3.3V CMOS TOLERANT 
#define ESC_PIN 18
#define POT_PIN 34

const int PWM_FREQ = 50;        // 50Hz RC frame
const int PWM_RESOLUTION = 16;  // 16-bit timer (65536 counts)
const int PWM_CHANNEL = 0;

void setup() {
  Serial.begin(115200);
  ledcSetup(PWM_CHANNEL, PWM_FREQ, PWM_RESOLUTION);
  ledcAttachPin(ESC_PIN, PWM_CHANNEL);

  // 1ms pulse out of 20ms = 5% duty cycle = 3276 counts
  ledcWrite(PWM_CHANNEL, 3276);
  Serial.println("[ARMING] Transmitting idle frame on ESP32...");
  delay(3500);
}

void loop() {
  int pot = analogRead(POT_PIN); // 0 to 4095
  int duty = map(pot, 0, 4095, 3276, 6553); // 1ms to 2ms
  ledcWrite(PWM_CHANNEL, duty);
  delay(20);
}

BENCHTOP TEST SAFETY PROTOCOLS

1. NEVER ATTACH PROPELLERS TO MOTORS ON THE BENCH. Bare-shaft testing only. Blades spinning at 20,000 RPM act as lethal laceration hazards.

2. MECHANICAL REACTION TORQUE CLAMP: Clamp motor housing securely to the bench. Unmounted motors will violently flip when throttle steps are applied.

3. CURRENT-LIMITED BENCH SUPPLY: Utilize an inline automotive fuse or smoke stopper current limiter during first power-up.
